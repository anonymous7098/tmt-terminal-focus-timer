# Music

Put local `.mp3`, `.wav`, `.ogg`, or `.flac` files in this folder. TMT scans the project folder recursively and lists every supported track automatically — no configuration needed.

The audio files in this folder are **ignored by Git by default** to keep the repository small and avoid accidentally publishing copyrighted music.

If you own the rights to the tracks and want them in the repository, remove the `[Mm]usic/**` rules from the root `.gitignore` and commit the files explicitly.
